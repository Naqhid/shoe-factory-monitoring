# 🎓 ProdPulse Individual Training Sessions
## One-on-One Role-Based Training

---

# 👷♂️ **TRAINING SESSION: PRODUCTION WORKERS**
*Duration: 2 hours | Format: Individual or small group*

## **🎯 Before the Session:**
- Ensure worker has smartphone/tablet
- Have their employee QR code ready
- Test mobile app access
- Prepare practice scenarios

## **📱 What You'll Teach Production Workers:**

### **Session Agenda:**

#### **1. Mobile App Setup (20 minutes)**
**Show them how to:**
- Open ProdPulse on their mobile browser
- Install the app on their phone (Add to Home Screen)
- Login with their username and password
- Navigate the mobile interface

**Practice Together:**
- Have them install the app
- Login and logout
- Show them the main mobile screen

#### **2. Employee QR Code Scanning (30 minutes)**
**Show them how to:**
- Find their personal employee QR code
- Use phone camera to scan their QR code
- Check in when starting work
- Check out when ending work/break
- What to do if scanning fails

**Practice Together:**
- Scan their employee QR code multiple times
- Practice check-in and check-out
- Try scanning in different lighting
- Handle scan errors

#### **3. Personal Production Tracking (40 minutes)**
**Show them how to:**
- Start their work session
- Update their production numbers
- Record completed pairs/items
- View their daily performance
- End their work session

**Practice Together:**
- Start a practice work session
- Enter sample production numbers
- Check their performance metrics
- End the session properly

#### **4. Basic Troubleshooting (20 minutes)**
**Show them what to do when:**
- App won't open or crashes
- QR code won't scan
- Can't login
- Internet connection issues
- Who to call for help (you/supervisor)

#### **5. Q&A and Practice (10 minutes)**
- Answer their questions
- Let them practice independently
- Confirm they understand everything

## **✅ Check Before They Leave:**
- [ ] Can open and login to mobile app
- [ ] Can scan their employee QR code successfully
- [ ] Can check in and check out
- [ ] Can update production numbers
- [ ] Knows who to contact for help
- [ ] Has app installed on their phone

# 👨💼 **TRAINING SESSION: SUPERVISORS**
*Duration: 4 hours | Format: Individual training*

## **🎯 Before the Session:**
- Prepare supervisor login credentials
- Have machine QR codes and employee QR codes ready
- Set up practice scenarios
- Prepare sample data for reports

## **💻 What You'll Teach Supervisors:**

### **Session Agenda:**

#### **1. Supervisor Dashboard Overview (45 minutes)**
**Show them how to:**
- Login to the supervisor dashboard
- Navigate different sections (Overview, Reports, etc.)
- Understand efficiency percentages and metrics
- Read machine status indicators (green/red)
- Use date selection to view historical data
- Interpret overall factory performance

**Practice Together:**
- Login and explore dashboard
- Check today's performance
- Look at yesterday's data
- Understand what each metric means

#### **2. QR Code Management - Dual Access (45 minutes)**
**Show them how to:**
- **Machine QR Codes**: Scan to get machine details, efficiency, status
- **Employee QR Codes**: Scan to check attendance, performance
- Switch between machine and employee views
- Use QR scanning for quick access to information

**Practice Together:**
- Scan different machine QR codes
- Scan different employee QR codes
- Show them the detailed information available
- Practice switching between views

#### **3. Team Management (60 minutes)**
**Show them how to:**
- Check team attendance using employee QR codes
- Monitor individual worker performance
- See who's present/absent today
- Track productivity by worker
- Assign workers to different lines
- Monitor work sessions

**Practice Together:**
- Check current team attendance
- Review individual worker data
- Practice assigning workers
- Monitor active work sessions

#### **4. Machine Monitoring (45 minutes)**
**Show them how to:**
- Use machine QR codes for instant machine access
- Monitor real-time machine status
- Check machine efficiency percentages
- Identify bottleneck machines
- View machine performance trends
- Schedule machine maintenance

**Practice Together:**
- Scan machine QR codes
- Check machine efficiency
- Identify underperforming machines
- Review machine trends

#### **5. Report Generation (60 minutes)**
**Show them how to:**
- Generate daily efficiency reports
- Create team performance reports
- Include QR scan data in reports
- Export reports to share with management
- Schedule automated reports
- Customize report parameters

**Practice Together:**
- Generate today's efficiency report
- Create team performance report
- Export report as PDF/Excel
- Set up automated daily report

#### **6. Decision Making & Actions (25 minutes)**
**Show them when and how to:**
- Intervene when efficiency drops
- Reassign workers based on performance
- Address machine bottlenecks
- Escalate issues to plant manager
- Use QR scan data for quick decisions

## **✅ Check Before They Leave:**
- [ ] Can navigate supervisor dashboard confidently
- [ ] Can scan both machine and employee QR codes
- [ ] Can monitor team attendance and performance
- [ ] Can identify machine bottlenecks
- [ ] Can generate and export reports
- [ ] Understands when to escalate issues
- [ ] Can make operational decisions using data
