# 📱 ProdPulse User Guide
## Smart Production Tracking System

---

## 🎯 **What is ProdPulse?**

ProdPulse is a comprehensive **real-time production monitoring system** designed specifically for shoe manufacturing facilities. It transforms your factory floor data into actionable insights, helping you track machine performance, monitor efficiency, and optimize production processes.

### **Key Benefits:**
- ✅ **Real-time Monitoring** - Track all machines and production lines instantly
- ✅ **Mobile Access** - Monitor from anywhere using smartphones/tablets
- ✅ **Efficiency Tracking** - Identify bottlenecks and optimize performance
- ✅ **Data-Driven Decisions** - Make informed choices based on actual production data
- ✅ **Quality Control** - Track rework and rejection rates
- ✅ **Attendance Management** - Monitor workforce presence and productivity

---

## 🏗️ **How ProdPulse Works**

### **System Architecture:**
```
Factory Machines → Data Collection → ProdPulse System → Real-time Dashboard
```

1. **Data Collection**: Machines send status data (running/idle) automatically
2. **Processing**: Backend processes and stores data in real-time
3. **Visualization**: Web dashboard displays live production metrics
4. **Mobile Access**: Workers and supervisors access data via mobile devices

## 📊 **Understanding the Metrics**

### **Efficiency Percentage**
- **90%+ (🟢)**: Excellent performance
- **70-89% (🟡)**: Good performance, room for improvement
- **Below 70% (🔴)**: Needs immediate attention

### **Machine Status**
- **🟢 Running (Status 1)**: Machine is actively producing
- **🔴 Idle (Status 0)**: Machine is stopped or not producing
- **⚠️ Attention**: Efficiency below acceptable threshold

### **Production Metrics**
- **Target**: Daily production goal (pairs of shoes)
- **Output**: Actual production achieved
- **Output %**: (Actual ÷ Target) × 100
- **Efficiency %**: Overall machine utilization rate

## 🛠️ **Troubleshooting**

### **Common Issues:**

#### **Dashboard Not Loading**
- Check internet connection
- Refresh browser page
- Clear browser cache
- Contact IT support if problem persists

#### **Data Not Updating**
- Check connection status indicator
- Verify backend server is running
- Refresh page manually
- Check machine connectivity

#### **Mobile App Issues**
- Ensure stable internet connection
- Update browser to latest version
- Clear browser cache and cookies
- Reinstall mobile app if necessary

#### **Login Problems**
- Verify username and password
- Check caps lock status
- Contact administrator for password reset
- Ensure account is active

## 📚 **Glossary**

**Efficiency**: Percentage of time a machine is productively running
**Output**: Number of shoe pairs produced
**Target**: Daily production goal
**Bottleneck**: Machine or process causing production delays
**Rework**: Items requiring additional work to meet quality standards
**Rejection**: Items that cannot be fixed and must be discarded
**Work Center**: Group of related machines or production area
**Session**: Period of active work by an employee
**PWA**: Progressive Web App - installable web application
